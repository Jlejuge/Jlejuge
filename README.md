# Empowered AI Project Insights Wireframes

This repository contains static HTML wireframes for the Empowered AI Project Insights experience.

## Project Structure

- `index.html` – Home page wireframe
- `features.html` – Feature showcase wireframe
- `getting-started.html` – Activation walkthrough wireframe
- `mastering-insights.html` – Advanced guidance wireframe
- `privacy-security.html` – Privacy & security wireframe
- `support-contact.html` – Support & feedback wireframe
- `uploads-summary.html` – Uploads and form entry summary
- `assets/` – Shared CSS styles

## Preview the Wireframes Locally

Because the project is a collection of static HTML files, you can serve them locally with any static file server. Two quick options:

### Option 1: Python 3

```bash
python3 -m http.server 8000
```

Then open your browser to <http://localhost:8000> and navigate between the pages with the site navigation.

### Option 2: Node.js (http-server)

```bash
npx http-server -p 8000
```

Again, browse to <http://localhost:8000> to exercise the prototype.

The pages are responsive, so resize the browser window or use device emulation tools to validate breakpoints. No build step is required.
